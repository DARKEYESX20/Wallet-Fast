# Wallet Fast

Quick expense logging for Android: tap a template, it's saved. Made a mistake? Undo it.

- One-tap templates (e.g. "Bus −₺10")
- Multiple accounts with a total balance
- Undo, grouped history, backup (export/import)
- Turkish and English
- Offline: all data stays on your phone

## Build

JDK 17, Android SDK 34.

```bash
./gradlew assembleRelease
```

GitHub Actions builds the APK on every push.
